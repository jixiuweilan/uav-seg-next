## 训练输入的 CPU 实现

`uavseg.data` 使用当前环境已有的 NumPy，没有模型运行时依赖：

- `Geometry` 保存裁剪位置、尺寸、两种翻转和四分之一转数。
  图像、标签按同一份记录依次裁剪、水平翻转、垂直翻转、旋转，不插值标签。
- `sample_geometry` 使用显式传入的局部随机数生成器，均匀抽样位置；记录可以复现。
  基线设计的512像素裁剪由调用者传入，不按标签内容挑选或丢弃难样本。
- `prepare_pair` 将 RGB uint8 转成连续的 CHW float32，除以255。
  标签0映射为-100，标签1至8映射为0至7；预测类别索引则映射回官方1至8。
- 不传变换时保留完整图像及标签，不做验证增强或缩放。
  全 Ignore 样本仍返回，`valid_pixels=0`；后续训练代码须据此跳过优化更新并限制消耗批次数。

```python
import numpy as np
from uavseg.data import sample_geometry, prepare_pair

# image 和 mask 由获授权的执行端加载；当前代码终端只使用合成数组。
rng = np.random.default_rng(0)
geometry = sample_geometry(mask.shape, (512, 512), rng)
sample = prepare_pair(image, mask, geometry)
```

0.4.0通过50项合成测试。新增检查覆盖手算的奇数尺寸裁剪/翻转/旋转、单像素目标、
标签映射、全 Ignore、随机变换重放、输入不可变、整组划分、完全重复约束、
类别覆盖、矛盾拒绝和输出保护。这是0.4.0交付时的验证记录；后续模型代码和内部指标
进度见[基线代码与执行端验证](baseline-runtime.md)，正式训练循环尚未实现。
