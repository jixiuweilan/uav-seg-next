## 已交付页面的操作参考（无需整轮重做）

使用负责人转交的本地原图复核 HTML，旧“中文复核练习.html”仅作历史材料。
完整步骤见[本地原图复核操作说明](local-original-review.md)。

1. 下载 HTML，用电脑浏览器打开，选择自己已有的训练原图目录。
2. 等待程序核对本批35张图；无需安装环境、克隆代码或集中传图。
3. 每次比较两张原图，查看固定地物，填判断、理由，勾选查看声明并保存本条。
4. 先做15条第一优先级，再做7条第二优先级。预计20–40分钟，可分次完成，
   遇到难例可以选存疑并说明缺什么证据，不要求凑齐确定结论。
5. 下载进度 JSON，交给负责人并注明“22条原图复核”；关闭前先确认下载成功。
   下次恢复 JSON 后继续。打不开或核对报错时，回报浏览器、步骤和提示即可。

本轮看图是为了核实可能影响训练/验证独立性的关系。人负责图像判断，
